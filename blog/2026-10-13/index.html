Daily briefing

  1. Unreachable Oracles introduces an offline audit for checking whether each benchmark answer can actually be derived from the information an agent receives. Its rule traces both the target value and every construction step through a declared, finite set of permitted derivations. QAMQOR and radarvitals-audit expose the related problem of test leakage through shared participants: scores can reflect recognition of a child, session, or subject rather than the intended capability. Together, these releases make benchmark validity a recurring design pressure in this captured feed. Why it matters: If you build or select evaluation suites, this means checking answer derivability and participant-separated splits can change whether a model score is interpretable before any model comparison begins. Evidence: E002, E004, E050. High confidence.
  2. GraphInstruct is a new progressive benchmark for graph generation, with 900 instructions arranged across six constraint levels and 1,782 algorithmically synthesized reference solutions in version 1.1. It scores outputs on five dimensions using deterministic metrics and releases the dataset, raw model responses, per-instance scores, reference pools, and a code snapshot. Why it matters: If you are comparing models that must produce structured graphs, this provides more diagnostic information than a single pass rate: performance can be separated by constraint difficulty and scoring dimension, while the released responses and code support result inspection and reruns. Evidence: E003. High confidence.
  3. SEBGen is a new framework that generates software-engineering agent tasks from code repositories and updates its generation strategies through an evolution loop. It scores candidate strategies across quality, novelty, difficulty coverage, skill diversity, and evolution potential rather than keeping one fixed task collection. Why it matters: If you maintain an agent benchmark, this changes the choice between a stable test set and a renewable one. SEBGen offers a concrete design for producing new tasks as existing sets become less discriminating, although the captured description does not establish how well its generated tasks hold up under independent validation. Evidence: E009. Medium confidence.
  4. The new unsafe-eval leaderboard dataset publishes the underlying results for prompt-safety evaluations, pins every benchmark to a fixed dataset revision, and records one result file per run with scores, token use, and cost. Why it matters: If you are choosing safety classifiers or general-purpose models, this lets you examine operating cost alongside scores and rerun the same prompt revision, reducing ambiguity caused by silent dataset changes or leaderboard-only reporting. Evidence: E020. High confidence.

类别观测之间的差异可能反映采集变化，而非领域变化。下载量变化并非单日变动，且仅来自一个平台。发布说明可用性，更新说明维护情况，讨论说明关注度；其中任何一项都不能单独证明使用情况、质量或影响力。
