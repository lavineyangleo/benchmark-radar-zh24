Daily briefing

  1. Autonomous Science Bench is a new benchmark in today’s captured feed that makes an agent choose batches of experiments under a fixed budget, receive measurements from a laboratory service, and revise its next experiments. Its initial six campaigns use published biology, chemistry, and materials-science experiments rather than only fixed datasets or simulations. Why it matters: If you are evaluating agents for scientific discovery, this artifact changes the choice from testing answers about existing data to testing whether an agent can spend a limited experimental budget productively and learn from each result before selecting the next experiment. Evidence: E001. High confidence.
  2. A new agent-benchmark audit study introduces oracle-integrity checks: state invariants and known-answer controls designed to detect defects in the software that decides whether an agent succeeded. The study reports detecting all seven injected defect classes and finding a reward-function defect that altered environment state before scoring. Why it matters: If you operate an agent leaderboard or use one for model selection, this means the scoring harness itself needs validation. Otherwise, a model comparison can reflect configuration-dependent state changes or faulty success checks rather than agent capability. Evidence: E011. High confidence.
  3. Bemula is a new benchmark for memory unlearning: whether a language-model agent can delete facts after an explicit user request while retaining unrelated memories. It contains 50 multi-session dialogues and 135 requests spanning six forgetting-request types. Why it matters: If you are selecting a memory system for assistants that retain personal information, ordinary retrieval scores are insufficient. Bemula adds separate evidence for targeted deletion and preservation, which directly informs privacy and data-removal decisions. Evidence: E010. High confidence.
  4. EvoWeb is a new coding-agent benchmark built around 320 cumulative requests across 32 persistent web applications. A browser agent tests each intermediate version for the new feature, integration with earlier work, and continued operation of previously requested features. Why it matters: If you are choosing a coding agent for ongoing product maintenance, this evaluates a different risk from one-shot code generation: whether repeated edits accumulate regressions. It can separate agents that satisfy the latest request from those that preserve a working product over time. Evidence: E017. High confidence.
  5. ToolHACE is a new span-level benchmark for detecting hallucinations after a language model has already called the correct tool and received accurate output. It targets contradictions, omitted details, and unsupported claims in the final response rather than concentrating only on tool selection and arguments. Why it matters: If you evaluate tool-using assistants, this means successful tool invocation cannot stand in for grounded output. ToolHACE supports a separate decision about whether the response faithfully carries tool evidence through to the user. Evidence: E025. High confidence.
  6. GIFT-Eval-CTX is a new forecasting benchmark with 10,000 instances across 20 datasets that supplies verified information about future events or conditions. Its design isolates whether a forecasting method can convert that information into improved numerical trajectories. Why it matters: If you are comparing forecasting systems that accept plans, events, or expert expectations as context, this offers a more targeted test than ordinary historical forecasting. It helps distinguish models that merely accept contextual text from models that use verified future information in their predictions. Evidence: E002. High confidence.

应增加针对测试系统本身的检查。验证评分不会改变环境，重新运行答案已知的对照测试，在长时任务中保留先前功能，测试按要求删除记忆的能力，并区分模型故障与工具或运行时故障。该信息流还包含安全审查方面的担忧，包括污染和薄弱的安全措施。[E004, E010, E011, E013, E017]

结论: 在比较模型之前，应审计评估器，并增加针对状态完整性、回归、删除、授权和恢复的测试。应首先将其应用于长时间运行或使用工具的系统。这项建议仅适用于今天的关键词过滤信息流；相互重叠的类别标签反映的是抓取记录中的侧重点，而非更广泛领域的情况。

另一种解读: 最有力的另一种解读是，这些成果主要提出了新的基准和框架，但没有独立复现证明其方法能够改善生产决策。因此，立即全面采用还为时过早；相比替换现有评估方案，开展小规模验证试点和评估器审计更有依据。[E010, E011, E013, E017]
